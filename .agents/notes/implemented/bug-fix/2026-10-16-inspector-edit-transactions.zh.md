# Agent Note: Inspector reflected-field transactions

Status: implemented

[English](2026-10-16-inspector-edit-transactions.md)

## Problem

Inspector 绘制即使没有控件变化，也会获取组件的可变引用。解引用会将组件
标记为 `Changed`，使使用变更筛选的系统处理空闲选中的实体。反射字段写入
也缺少用户操作的起止范围和撤销补偿。

## Decision

Inspector 使用组件的共享引用绘制，控件修改独立的叶子值草稿。支持的字段值
和具体组件的访问回调属于编辑器，不属于反射 trait。动作按需解析命名字段路径，
在获取 ECS 可变访问前校验目标和值类型。撤销保存字段快照，而非整个组件。

连续编辑使用已有编辑器历史，一个手势对应一个补偿。其他历史操作开始前先结束
待完成编辑，以保持执行顺序。运行时契约见
[architecture.md](../../../../docs/architecture.md#reflection-and-the-inspector)。

## Alternatives considered

**克隆并比较整个组件。** 未采用：注册需要额外的克隆和相等比较约束，撤销还可能
覆盖无关字段或忽略字段。叶子快照适用于未实现克隆的组件。

**绘制时绕过 ECS 变更检测。** 未采用：编辑器需要单独的变更标记路径，并在组件
已被修改后信任控件报告。共享引用绘制使空闲 UI 不会进入 ECS 可变访问路径。

## Consequences

反射保持命名字段访问接口，不增加动态克隆或序列化。编辑器的独立值类型集合
对应其支持的控件，其余叶子不支持编辑。字符串控件在空闲帧也需要独立草稿；
数值和数学类型的草稿通过值复制获得。

历史校验当前实体代际、组件是否存在、字段路径和叶子类型，不保留 ECS 引用。
移除组件或字段可能使记录暂时无法应用；失败的历史操作保留记录，允许重试。
编辑器动作之外的修改和组件 hook 副作用没有通用的历史或回滚机制。

无窗口测试覆盖空闲绘制、真实 egui 输入、嵌套的非克隆组件、值未变化、失效目标、
批次校验，以及手势结束和历史顺序。
