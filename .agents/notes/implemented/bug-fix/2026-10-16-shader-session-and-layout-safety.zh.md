# Agent Note: Shader session synchronization and reflected layouts

Status: implemented

[English](2026-10-16-shader-session-and-layout-safety.md)

## Problem

字节码缓存和反射缓存分别使用互斥锁，却共用一个 Slang 全局会话。
两个缓存同时未命中时，可以并发进入该会话。`Reflection` 还通过手写的
`Send`/`Sync` 实现暴露未同步的惰性查询；持有反射指针只能保证生命周期，
不能保证线程安全。

`RootBinder::set_bytes` 接受短于存储范围的输入，随后复制到整个参数范围，
导致 panic。结构体代码生成把反射偏移写入注释，却没有在 Rust 字段中表达
对齐和填充。紧密排列的矩阵数组也没有包含反射报告的存储填充。

## Decision

全局会话是同步与所有权的单位。锁定版本的 Slang 绑定为其拥有的会话和组件
对象提供 `Send`，因此 Rust 互斥锁可提供共享访问，无需手写线程标记。
反射持有其来源全局会话；原生程序的释放与编译、查询使用同一把锁。
原生反射节点只在这些操作内部使用，返回的布局是数值快照。

根参数写入要求精确的存储长度。生成的 Rust 结构体通过显式字节填充和对齐
表达反射偏移与总大小。矩阵字段描述包含填充的物理存储，而非紧密排列的
数学元素列表。运行时契约位于
[architecture.md](../../../../docs/architecture.md#assets)。

## Alternatives considered

- **每个反射程序各有一把锁。** 拒绝：不同程序和编译会话可以共用一个
  全局会话，程序局部锁无法同步对该会话的全部访问。
- **返回布局时保留会话锁。** 拒绝：调用方持有一个布局时查询另一个布局
  将要求递归加锁。数值快照让布局检查不再调用原生接口。
- **允许部分根参数写入。** 拒绝：该 API 提供完整参数值；主机镜像过短
  表示布局不匹配，而非有意更新一个子范围。
- **拒绝所有需要填充的结构体或矩阵。** 拒绝：显式存储可以表达这些布局，
  同时保留现有的源码生成 API。

## Consequences

共用全局会话的编译、查询和反射程序销毁串行执行；独立编译器仍使用各自的锁。
布局查询分配拥有字段偏移的快照。反射节点不会离开同步所有者，返回的反射
在 `Compiler` 句柄销毁后仍可使用。

回归测试覆盖锁的互斥和并发缓存调用，验证长度错误不会修改根参数数据，
并在保留 `bytemuck` 派生的情况下编译生成结构体，再把 Rust 大小与字段
偏移和 Slang 反射对照。代码生成不支持的字段类型仍返回错误。
