# Agent Note: egui stack bumped to 0.36 as one change

Status: implemented

[中文](2026-08-22-egui-stack-0-36.zh.md)

## Problem

The egui stack (egui / egui-winit / egui_dock) is version-locked: egui_dock
compiles against exactly one egui release line, so the three dependabot PRs
bumping each crate individually (#27 egui_dock 0.18→0.21.1, #28 egui-winit
0.33→0.36.1, #29 egui 0.33→0.36.1) each fail CI on their own.

## Decision

One atomic bump in `crates/moonfield-editor/Cargo.toml`: egui 0.36.1,
egui-winit 0.36.1, egui_dock 0.21.1. winit stays at 0.30 (egui-winit 0.36.1
accepts winit ^0.30.13); ash stays at 0.38. The breakage absorbed:

- egui 0.36 removed `Context::run`; the frame is built with
  `Context::run_ui`, and panels (`CentralPanel`) are shown inside the root
  `Ui` it provides instead of on the `Context`.
- epaint 0.36 changed `TexturesDelta::set` to
  `HashMap<TextureId, SmallVec<[ImageDelta; 1]>>` (several partial deltas per
  texture per frame) and debug-asserts that a dropped `TexturesDelta` is
  empty. The editor drains `set`/`free` as it applies them, matching
  egui-wgpu 0.36's winit integration; tests that discard the output call
  `FullOutput::drop_without_applying_deltas`.
- egui_dock 0.21 removed `DockArea::show(ctx, …)`; the editor wraps
  `show_inside(ui, …)` in a margin-less transparent `CentralPanel`
  (`Frame::NONE`), mirroring what 0.18's `show` did internally.
- egui_dock 0.21's `TabViewer` requires `fn id(&mut self, tab) -> Id`.

The in-house egui→Vulkan backend (`egui_vk.rs`) needed no changes of its
own; its feature-spec reference is now egui-wgpu 0.36. The stack anchor in
the root `AGENTS.md` reads egui 0.36 / egui-winit 0.36 / egui_dock 0.21.

## Alternatives considered

- **Merge the three dependabot PRs individually.** Impossible: the stack is
  version-locked, so each PR fails CI alone; merging any one of them breaks
  the build on master.
- **Bump egui and egui-winit, hold egui_dock at 0.18.** Impossible for the
  same reason in reverse: egui_dock 0.18 only compiles against egui 0.33.
- **Stay on the 0.33 stack.** Rejected: it accumulates maintenance debt and
  leaves dependabot opening unmergeable PRs; the bump only grows larger.

## Consequences

- `cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
  and `cargo test --workspace` (including the Vulkan-backed
  `tests/egui_headless.rs`) pass on the new stack.
- Building the workspace now requires rustc ≥ 1.95 (egui 0.36's MSRV).
- The bump supersedes dependabot PRs #27, #28, and #29.
- Future egui bumps follow the same rule: one atomic change per stack line,
  with `egui_vk.rs` checked against the matching egui-wgpu release.
