# Agent Note: egui stack bumped to 0.36 as one change

Status: implemented

[English](2026-08-22-egui-stack-0-36.md)

## Problem

egui 栈(egui / egui-winit / egui_dock)版本互相锁定:egui_dock 只能对着
唯一一条 egui 发布线编译,因此三个分别升级单个 crate 的 dependabot PR
(#27 egui_dock 0.18→0.21.1、#28 egui-winit 0.33→0.36.1、#29 egui
0.33→0.36.1)单独都无法通过 CI。

## Decision

在 `crates/moonfield-editor/Cargo.toml` 中一次性原子升级:egui 0.36.1、
egui-winit 0.36.1、egui_dock 0.21.1。winit 保持 0.30(egui-winit 0.36.1
接受 winit ^0.30.13);ash 保持 0.38。消化的破坏性变更:

- egui 0.36 移除了 `Context::run`;每帧改用 `Context::run_ui` 构建,面板
  (`CentralPanel`) 在其提供的根 `Ui` 内显示,而不再直接作用于 `Context`。
- epaint 0.36 把 `TexturesDelta::set` 改为
  `HashMap<TextureId, SmallVec<[ImageDelta; 1]>>`(同一纹理一帧内可携带多条
  局部更新),并对非空丢弃的 `TexturesDelta` 触发 debug_assert。编辑器在应用时
  排空 `set`/`free`,与 egui-wgpu 0.36 的 winit 集成一致;丢弃输出的测试调用
  `FullOutput::drop_without_applying_deltas`。
- egui_dock 0.21 移除了 `DockArea::show(ctx, …)`;编辑器用无边距透明
  `CentralPanel`(`Frame::NONE`)包裹 `show_inside(ui, …)`,与 0.18 的
  `show` 内部实现一致。
- egui_dock 0.21 的 `TabViewer` 要求实现 `fn id(&mut self, tab) -> Id`。

自研的 egui→Vulkan 后端(`egui_vk.rs`)本身无需改动;其功能规格参照物更新为
egui-wgpu 0.36。根 `AGENTS.md` 中的栈锚点现为 egui 0.36 / egui-winit 0.36 /
egui_dock 0.21。

## Alternatives considered

- **单独合并三个 dependabot PR。** 不可行:栈版本互相锁定,每个 PR 单独都无法
  通过 CI;合并其中任何一个都会破坏 master 的构建。
- **只升级 egui 和 egui-winit,egui_dock 留在 0.18。** 反向同样不可行:
  egui_dock 0.18 只能对着 egui 0.33 编译。
- **停留在 0.33 栈。** 否决:这会积累维护债,并让 dependabot 持续开出无法合并的
  PR;拖延只会让升级面更大。

## Consequences

- `cargo fmt --check`、`cargo clippy --workspace --all-targets -D warnings`、
  `cargo test --workspace`(含走 Vulkan 的 `tests/egui_headless.rs`)在新栈上
  全部通过。
- 构建 workspace 现在要求 rustc ≥ 1.95(egui 0.36 的 MSRV)。
- 本次升级取代 dependabot PR #27、#28、#29。
- 今后的 egui 升级遵循同一规则:每条栈线一次原子变更,并对照对应的 egui-wgpu
  发布检查 `egui_vk.rs`。
